# Personal Portfolio Website

A simple responsive portfolio built with HTML5 and CSS3 for a first-year
engineering student.

## Files

- `index.html` - page structure and content
- `style.css` - external stylesheet
- `assets/` - profile and project images

## Run locally

Open `index.html` in a browser, or use VS Code Live Server.

## Personalize

Update the LinkedIn and GitHub links in `index.html` with your real profile
URLs before submitting the assignment.
