# Personal Portfolio Website

A simple responsive portfolio built with HTML5 and CSS3 for a first-year
engineering student.

## Files

- `index.html` - page structure and content
- `style.css` - external stylesheet
- `assets/` - profile and project images

## Run locally

Open `index.html` in a browser, or use VS Code Live Server.

## Personalize

Replace the example email in `index.html` and update the LinkedIn and GitHub
links with your real profile URLs.
